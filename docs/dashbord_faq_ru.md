# Dashboard: руководство

Этот экран помогает запустить аудит сайта без командной строки. Сначала
введите адрес сайта, выберите профиль проверки и нажмите **Запустить**.
После завершения можно открыть отчет, сохранить его или задать вопрос AI-
помощнику.

## Как открыть dashboard

Запустите локальный сервер AgentReady Tools и откройте адрес dashboard,
который он покажет в консоли. Если язык не указан в адресе, dashboard
определяет его по языку браузера: для `ru` используется русский, для
остальных языков — английский.

Справа находится кнопка **Справка** рядом с выбором языка. Нажмите её, чтобы
открыть встроенную краткую справку на всю высоту страницы. Повторное нажатие
**Скрыть справку** убирает панель. Ширину панели можно менять за её левый
край на desktop.

Переключатель **Язык** в правом верхнем углу меняет язык интерфейса. Выбор
сохраняется в браузере. Если в адресе явно указан `?language=en` или
`?language=ru`, этот выбор имеет приоритет.

## Основные поля

| Элемент | Что сделать |
|---|---|
| **URL сайта** | Вставьте полный публичный адрес, например `https://example.com`. |
| **Профиль аудита** | Выберите тип проверки: все проверки, контент, API, AI Search/GEO, SEO или мобильная версия. |
| **Запустить** | Начинает аудит с выбранными настройками. |
| Значок `?` | Наведите мышь или перейдите к нему клавишей Tab, чтобы увидеть подсказку. |

Проверяйте только сайты, которые вы вправе анализировать. Приватные и
локальные адреса защищены и не принимаются.

## Дополнительные параметры

Откройте блок **Расширенные параметры**, если нужно точнее настроить запуск:

- **URL контента** — отдельная страница для контентных проверок.
- **URL магазина** — адрес, по которому нужно проверить сигналы commerce.
- **Тайм-аут** — сколько секунд ждать один сетевой запрос.
- **Потоки** — сколько проверок выполнять параллельно.
- **Порог уровня** — минимальная доля выполненных требований для следующего
  уровня зрелости.
- **Лимит рекомендаций** — сколько рекомендаций показать в отчете.
- **Проверять digests Agent Skills** — проверять содержимое навыков, а не
  только ссылки на них.

## Ссылки под настройками

- **Обновить каталог проверок** показывает доступные проверки выбранного
  профиля.
- **Проверить состояние сервиса** выполняет короткую проверку локального
  сервера.
- **AI** открывает настройки AI-провайдера.
- **Отладка результатов** показывает необработанный JSON ответа сервера.
  Включайте эту опцию, если нужно передать технические данные для поиска
  ошибки.

## Выбор отдельных проверок

Откройте **Проверки, включенные в запуск**. Кнопка **Выбрать все** включает
все проверки профиля, а **Очистить выбор** снимает их. Затем можно отметить
только нужные пункты. Описание каждой проверки находится рядом с ее
названием.

## Результат аудита

После запуска dashboard показывает ход работы: начало, получение данных и
формирование отчета. В готовом отчете смотрите:

- общий балл и уровень зрелости;
- успешные, проблемные и пропущенные проверки;
- рекомендации с приоритетом;
- подтвержденные URL, страницы, ресурсы и метрики, если они есть.

Кнопки **Скачать отчет** и **Распечатать отчет** находятся рядом с HTML-
отчетом. Скачанный файл можно открыть без сервера.

## AI-помощник

AI-панель появляется после завершения подходящего аудита. Она использует
данные текущего отчета в качестве отправных данных для анализа.

1. Выберите режим **SEO**, **GEO** или **SEO/GEO**.
2. Выберите провайдера и модель.
3. В поле **Запрос** напишите вопрос простыми словами или выберите готовый
   запрос из библиотеки.
4. При необходимости выберите **Навыки** и **MCP context**. Навыки задают
   стиль анализа, а MCP добавляет подтвержденные данные AgentReady.
5. Нажмите **Спросить AI-помощника** для отдельного ответа или
   **Открыть чат с AI-помощником** для последовательного диалога.

**История диалога** помогает задавать уточняющие вопросы. **Повторить
последний запрос** запускает предыдущий запрос еще раз. **Новый диалог**
очищает текущую беседу.

## Файлы, prompts и сохранение

- **Прикрепить файлы** добавляет изображения и документы, которые нужны для
  анализа.
- **Библиотека prompts** содержит готовые SEO/GEO запросы.
- **Название prompt** используется при сохранении собственного запроса.
- **Сохранить prompt** добавляет его в библиотеку.
- **Сохранить чат в файл** сохраняет историю диалога.
- **Экспорт OpenAI/DeepSeek JSON** создает переносимый JSON.
- **Сохраненные чаты** открывает ранее сохраненный диалог.

Не вставляйте API-ключ в текст запроса. Ключи провайдеров сохраняются в
системном хранилище, а не в обычном тексте dashboard.

## Если что-то не работает

1. Проверьте URL и подключение к интернету.
2. Нажмите **Проверить состояние сервиса**.
3. Убедитесь, что AI-провайдер включен и выбранная модель доступна.
4. Для диагностики включите **Отладка результатов** и сохраните сообщение
   об ошибке.
5. Если AI не отвечает вовремя, проверьте адрес провайдера, модель и
   сетевой доступ.
